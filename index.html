개인 영상 제작 도구 안내

Video Production Workspace

Google Drive에 보관한 제작 자료를 사용해 영상을 편집하고, 결과를 같은 계정의 Drive에 저장하는 개인용 도구입니다.

하는 일

  • 사용자가 선택하거나 이 앱으로 만든 제작 폴더와 파일에 접근합니다.
  • 영상 클립, 나레이션 파일, SRT 자막을 내려받아 FFmpeg로 합성합니다.
  • 사용자가 수동 실행한 GitHub Actions에서 편집할 수 있습니다.
  • 완성 영상을 Drive에 저장하고 사용자가 직접 검수합니다.

Google 계정 비밀번호를 수집하지 않습니다. Google 공식 OAuth와 파일 선택기를 사용하며, 요청 권한은 drive.file입니다. 이 권한은 선택된 파일의 확인·수정·생성·삭제를 허용합니다. 통상 편집 흐름에서는 기존 파일을 삭제하지 않으며, 사용자가 정리를 명시적으로 요청한 경우 별도 확인을 거쳐 휴지통으로 옮길 수 있습니다.

현재 이용 범위

계정 소유자의 개인 제작에 사용합니다. 일반 대중을 위한 회원가입, 공개 영상 업로드, 결제 기능을 제공하지 않습니다. Google 또는 GitHub의 공식 제품이 아닙니다.
