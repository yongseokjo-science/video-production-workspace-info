대상 앱: Video Production Workspace
작성일: 2026년 10월 30일

접근하는 정보와 목적

사용자 확인을 위한 Google 계정 이메일, 선택한 제작 폴더·파일의 이름·ID·형식·크기·해시와 영상·음원·자막 파일에 접근합니다. 계정 확인, 제작 자료 다운로드, 영상 편집, 결과 저장, 오류 확인과 중복 처리 방지에 사용합니다.

인증과 권한

Google 공식 OAuth로 동의받으며 계정 비밀번호를 수집하지 않습니다. drive.file을 요청하고, Google Picker로 선택하거나 앱으로 만든 파일에 접근합니다. 파일 선택은 해당 파일에 대한 확인·수정·생성·삭제 권한을 포함합니다. Drive 전체 읽기 권한을 기본으로 요청하지 않습니다.

보관 위치와 처리 서비스

  • 입력·완성 영상은 사용자의 Google Drive에 보관합니다.
  • 최초 설정 PC의 보호 경로에 OAuth 인증정보를 저장할 수 있습니다. 클라우드 운영을 선택하면 갱신 토큰과 OAuth 클라이언트 인증정보를 비공개 GitHub 저장소의 암호화된 Actions Secret에 저장합니다.
  • GitHub Actions는 실행 중 영상·음원·자막·인증정보를 처리합니다. 인증정보는 워크플로 환경에서 사용하며 정상 실행 후 임시 미디어를 정리합니다. 토큰을 소스나 일반 로그에 출력하지 않도록 구성합니다.
  • 실행 상태, 파일 ID·결과 링크·규격·해시 등 기술 정보는 비공개 실행 로그와 검증 기록에 남을 수 있습니다. GitHub의 보관 정책과 저장소 설정이 적용됩니다.
  • 로컬 검증을 수행하면 다운로드한 미디어·검증 기록은 작업 PC에 남을 수 있습니다.

공유와 이용 제한

제작과 저장을 위해 Google Drive와 GitHub Actions에 필요한 정보가 전달됩니다. 이 앱은 Google 사용자 데이터를 판매하거나 광고에 이용하지 않으며, 일반 AI 모델 학습 목적으로 사용하지 않습니다. 영상 공개 게시 또는 다른 서비스 전송은 별도의 사용자 지시가 필요합니다.

Google API에서 받은 정보의 사용과 다른 앱으로의 이전은 Google API 서비스 사용자 데이터 정책과 Limited Use 요구사항을 준수합니다.

보관 기간·철회·삭제

Drive 제작 파일과 로컬 검증자료는 사용자가 정리할 때까지 보관될 수 있습니다. 인증정보는 운영에 필요한 동안 저장하며, 사용을 중단하면 Google 계정의 타사 연결에서 앱 접근을 철회하고 GitHub Secret 및 로컬 인증 파일을 삭제할 수 있습니다. 접근 철회만으로 Drive의 기존 제작 파일이나 이미 남은 로그가 자동 삭제되지는 않습니다. 로그·결과·백업은 각 저장 위치에서 별도로 정리해야 합니다.

문의와 변경

문의는 OAuth 동의 화면에 표시된 사용자 지원 이메일로 받습니다. 다른 사람의 제작자료나 비밀번호·토큰을 문의에 포함하지 마세요. 처리 방식이 바뀌면 이 페이지를 갱신합니다. 운영자: yongseokjo-science.
